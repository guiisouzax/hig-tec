# Landing Page - Assistência Técnica

## Sobre o projeto

Este projeto consiste no desenvolvimento de uma **landing page para uma assistência técnica**, criada com o objetivo de apresentar a empresa, facilitar o contato com os clientes e divulgar seus principais canais de comunicação.

A página possui um design moderno e intuitivo, reunindo botões que direcionam os usuários para as principais redes sociais e meios de contato da empresa, proporcionando uma navegação rápida e acessível.

## Funcionalidades

* Página de apresentação da assistência técnica.
* Botão para contato via **WhatsApp**.
* Link para o **Instagram**.
* Link para Avaliações do **Google**.
* Interface responsiva para diferentes dispositivos.
* Projeto publicado e acessível online.

## Tecnologias utilizadas

* HTML5
* CSS3
* Vercel (Hospedagem)

## Objetivos

* Desenvolver uma página institucional para uma assistência técnica.
* Criar uma interface limpa, moderna e de fácil navegação.
* Aplicar conceitos de HTML e CSS na construção de uma landing page.
* Disponibilizar um canal de contato rápido por meio das redes sociais.
